Chatbot Kantin Koperasi

SIMULASI SECURE / AMAN

Kebijakan

Chatbot hanya boleh menjawab menu dan harga. Voucher hanya boleh dibuat oleh kasir.

Versi aman memisahkan aturan dari pesan pengguna dan tidak menyediakan fungsi pembuat voucher. Ini adalah simulasi lokal berbasis aturan, tanpa API LLM atau layanan luar.

Percakapan

Bot: Halo! Saya dapat membantu informasi menu dan harga kantin.
